# Mevora Rive assets

Drop licensed `.riv` files into these folders. The app already points at
the filenames below. If a file is missing, Flutter fallbacks are used.

| File | Purpose | Suggested license |
| --- | --- | --- |
| `common/loading.riv` | Shared loading | Commercial-use Rive Community or original export |
| `common/success.riv` | Success / complete | same |
| `common/error.riv` | Error states | same |
| `common/empty.riv` | Generic empty | same |
| `authentication/login_ambient.riv` | Subtle login atmosphere | same |
| `onboarding/complete.riv` | Onboarding complete | same |
| `onboarding/photo_upload.riv` | Photo upload status | same |
| `matching/match.riv` | Match celebration | same |
| `matching/empty_profiles.riv` | Discovery empty | same |
| `matching/empty_matches.riv` | Matches list empty | same |
| `chat/empty.riv` | Empty conversation | same |

Do not add files that lack commercial-use rights for Mevora.
